# Help Desk Ticket System

A modular Python-based Help Desk Ticket Management System.

The application allows users to create support tickets and provides
basic ticket management features such as priority, assignment,
status tracking, comments, and statistics.

## Features

### User Management

- Add user
- View users
- Search users
- Delete users

### Ticket Management

- Create ticket
- View tickets
- View ticket details
- Search tickets
- Update ticket status
- Assign tickets
- Add comments
- Delete tickets

### Reports

- Total tickets
- Open tickets
- In-progress tickets
- Resolved tickets
- Closed tickets
- Critical tickets

## Technologies

- Python
- JSON
- File Handling
- Datetime
- Modular Programming
